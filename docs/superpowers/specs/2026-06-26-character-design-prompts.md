# Knight's Treasure — Character Design Prompt Pack (per-emotion)

**17 characters · 105 single-emotion prompts.** Art direction is locked to a **stylized 3D Supercell
/ Clash-Royale render** based on the approved Knight reference. Every block below is a **standalone
prompt for one emotion** — copy it and it generates that single portrait. The bold label above each
block is the target asset filename.

- **Asset path convention:** `www/assets/images/characters/<character>/<character>_<emotion>.png`
- **Source of truth:** synced 1:1 with the rendered assets and `www/js/data/story.js`.

### Locked decisions (delegated — recorded per CLAUDE.md)
1. **Render style** = stylized 3D Supercell/Clash-Royale (glossy PBR, heroic-cartoon proportions,
   neutral studio lighting). Canon for the whole cast.
2. **Palette** = render style is shared; each character keeps a role-appropriate palette.
3. **Framing** = full body by default, matching the approved cast lineup. The **Cave Spirit** is a
   small floating sprite (upper body trailing into wisps, no legs); the **Dragon** is shown
   full-figure at creature scale (largest of the cast).
4. **Per-emotion** = one prompt per emotion (this file), single figure, no turnaround.
5. **Height to scale** = each character has a fixed height vs the Knight (baseline 1.0 / ~1.8 m), so
   the cast stays proportional when characters share a scene.

**Shared style tail** (baked into every block): *Supercell / Clash Royale stylized 3D mobile-game
art, semi-realistic cartoon, glossy PBR materials, soft subsurface, clean specular highlights,
neutral studio grey background, soft three-point studio lighting, gentle rim light, soft contact
shadow, Octane/Redshift game key art, high detail.*
