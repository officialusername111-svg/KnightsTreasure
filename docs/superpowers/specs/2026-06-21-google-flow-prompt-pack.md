# Knight's Treasure — Google Flow Prompt Pack (exact, copy-paste)

> One ready-to-paste prompt per asset. The style line is already inlined in every prompt — no prefix to add. Pairs with `2026-06-21-image-filename-checklist.md` (filenames) and `2026-06-21-asset-status-and-remaining-prompts.md` (status). **Date:** 2026-06-21 · **Updated:** sheet labels below each pose + divider line for clean cropping.

## How to run in Google Flow
1. Use Flow's **image generation** (Imagen "Ingredients"). Paste a prompt below.
2. **For expression sheets:** attach that character's existing base PNG (from `www/assets/images/characters/<char>/`) as a **reference ingredient** so the face/outfit stays identical across poses.
3. **Aspect ratio:** character sheets → horizontal (16:9); icons/badges/tiles → square (1:1); backgrounds → portrait (9:16).
4. **Sheet layout for clean cropping:** each character sheet prompt asks for an even grid with equal gutters, the pose centered in the upper part of its cell, a thin horizontal divider line, then the expression name labelled below it. Slice each cell, then trim at the divider to drop the label.
5. **After generating:** Flow can't export transparency — remove the grey background (remove.bg) and crop the ✦ watermark. Then slice sheets into the per-expression filenames in the checklist.
6. ✅ = already generated (prompt kept for re-rolls). ⬜ = needed.
